# RFC 索引与模板（any2api）

跨团队、不可逆、技术不确定，或影响公共接口 / 数据模型 / 安全隐私的方案才建 RFC；小改在变更文档评审即可。

## 目录规则

- 当前目录只放 RFC；不在 `docs/` 顶层另建 `rfcs/`。
- 文件名使用语义化主题，不分配 `RFC-xxxx` 顺序编号；历史编号仅用于追溯。
- 新建 RFC 后同步更新 [`../index.md`](../index.md) 状态表。

## 最小模板

```markdown
# <主题>

| 项 | 内容 |
|---|---|
| 类型 | RFC |
| 状态 | 草案 / 评审中 / 已接受 / 已拒绝 / 被替代 |
| Owner | |
| 关联 | 产品规格 / 变更文档 / ADR |

## 1. 背景与问题
## 2. 目标与非目标
## 3. 方案
## 4. 风险与替代方案
## 5. 验证与回滚
```
