# Triage 标签

技能以五个规范角色沟通；本文件把角色映射到本仓库 issue tracker 的实际标签字符串。

| 技能中的角色      | 本仓库标签        | 含义                     |
| ----------------- | ----------------- | ------------------------ |
| `needs-triage`    | `needs-triage`    | 待维护者评估             |
| `needs-info`      | `needs-info`      | 等待报告者补充信息       |
| `ready-for-agent` | `ready-for-agent` | 已完全定义，可交给 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现             |
| `wontfix`         | `wontfix`         | 不予处理                 |

技能提到某个角色时，使用本表对应标签。GitHub 已有 `wontfix`，其余四个在 setup 时创建。
